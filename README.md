
# AI Resume Builder

## Overview
AI Resume Builder is a simple web application that helps users create professional resumes quickly. Users can enter their personal information, skills, education, and experience, and the application generates a formatted resume.

## Features
- Enter personal information
- Add education details
- Add work experience
- Add skills
- Generate resume instantly
- Clean and responsive design

## Tech Stack
- HTML5
- CSS3
- JavaScript
